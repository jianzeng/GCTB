## 📊 Feature 1: Progress Bars

### What It Does

Shows estimated progress during MCMC runs:

```bash
  MCMC Progress:  45%|████████░░░░░░░░| 4500/10000 [03:25<04:10, 20ms/iter]
```

### How to Use

**CLI - Bayes:**
```bash
python3 -m gctb.cli bayes --bfile data --pheno pheno.txt \
    --bayes C --progress
```

**CLI - SBayes:**
```bash
python3 -m gctb.cli sbayes --ldm ldm --gwas-summary gwas.ma \
    --sbayes R --progress
```

### Technical Details

- Uses `tqdm` library (already in requirements.txt)
- Runs C++ MCMC in background thread
- Shows estimated progress (updates every 0.5s)
- Minimal overhead (~2-5%)
- GIL released during C++ computation

### When to Use

✅ **Use when:**
- Running interactively (want to see progress)
- Long chains (>5000 iterations)
- Want to know time remaining

❌ **Don't use when:**
- Batch/script mode (no terminal)
- Short chains (<1000 iterations)
- Redirecting output to file

## 🔬 Feature 2: Convergence Diagnostics

### What It Does

Assesses MCMC convergence quality:

```
==================================================
Convergence Diagnostics:
==================================================
Chain length: 1000, Burn-in: 100
Effective samples: 900

Parameter       Mean         ESS   Geweke Z  Status
--------------------------------------------------
hsq             0.4876       245     -0.83    ✓ Good
Pi              0.0089       198      0.67    ✓ Good
GenVar          0.4521       256     -0.92    ✓ Good
ResVar          0.4762       234      1.12    ✓ Good

Interpretation:
  ESS (Effective Sample Size): Higher is better
    > 400: Excellent
    > 100: Good
    > 50:  Fair
    < 50:  Poor (consider longer chain)
  
  Geweke Z-score: Should be |Z| < 2 for convergence
    |Z| < 2: Good (chain converged)
    |Z| < 3: Fair (possibly converged)
    |Z| > 3: Poor (chain not converged, run longer)
==================================================
```

### How to Use

**CLI - Bayes:**
```bash
python3 -m gctb.cli bayes --bfile data --pheno pheno.txt \
    --bayes C --diagnostics
```

**CLI - SBayes:**
```bash
python3 -m gctb.cli sbayes --ldm ldm --gwas-summary gwas.ma \
    --sbayes R --diagnostics
```

**Python API:**
```python
import gctb
from gctb.diagnostics import check_convergence, recommend_chain_length

# Run MCMC
results = gctb.run_mcmc(model, chain_length=1000, burnin=100)

# Check convergence
diag = check_convergence(results, 1000, 100, verbose=True)

# Get recommendations
needs_longer, message, _ = recommend_chain_length(diag)
if needs_longer:
    print(message)
```

### Metrics Provided

1. **Effective Sample Size (ESS)**
   - Measures independent information in correlated samples
   - Higher = better
   - >100 is good, >400 is excellent

2. **Geweke Z-Score**
   - Tests if early and late chain parts have same mean
   - |Z| < 2 means converged
   - |Z| > 3 means not converged

3. **Recommendations**
   - Automatically suggests if chain should be longer
   - Provides specific guidance

### Technical Details

- Uses `scipy` library (already in requirements.txt)
- Runs after MCMC (not during)
- Minimal overhead (<1%)
- Only checks parameter convergence (not individual SNPs)

### When to Use

✅ **Use when:**
- First analysis of new data
- Unsure of appropriate chain length
- Want publication-quality results
- Results seem unexpected

❌ **Don't use when:**
- Very confident in chain length
- Batch processing (adds output)
- Want absolute fastest run

## 🚀 Usage Examples

### Example 1: Default (No Extras) - FASTEST

```bash
# Fastest: No progress, no diagnostics
python3 -m gctb.cli bayes --bfile data --pheno pheno.txt \
    --bayes C --chain-length 1000 --out results
```

**Use for:** Batch jobs, production runs


**Use for:** Interactive long runs

```bash
# Check convergence quality

    --bayes C --chain-length 1000 --diagnostics --out results
```

**Use for:** First analysis, quality checks

```bash
    --bayes C --chain-length 5000 --progress --diagnostics --out results
```

**Use for:** Interactive quality-controlled runs
